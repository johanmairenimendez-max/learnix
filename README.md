# Learnix — Aprende, Gestiona, Crece

Plataforma de tecnología educativa de Lic. Johan Mendez (Distrito Educativo 03-03, San José de Ocoa).

## Módulos
Learnix Attendance · Learnix Planner · Learnix Students · Learnix Reports (próximamente)

## Páginas
Inicio, Publicaciones, Lectura, Recursos, Panel, Gestión, Editor, Biblioteca, Moderación, Perfil (foto de perfil editable) y Admin (login demo).

## Tecnologías
HTML5 + Tailwind CSS (CDN) + JavaScript vanilla + IndexedDB (db.js). Tipografías: Plus Jakarta Sans e Inter.

## Despliegue
Sitio estático en Render (Static Site, Publish Directory `.`, sin build).
